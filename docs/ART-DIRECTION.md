
# MONKEY MIND III
## Official Art Direction

### Visual Identity

- Genre: Cinematic 2D action-adventure platformer
- Style: Premium 32-bit-inspired pixel art
- Perspective: Side-scrolling 2D
- Display resolution: 1280 x 720
- Proposed art resolution: 640 x 360
- Performance target: 60 FPS

### Artistic References

- Metal Slug: Animation and visual effects
- Street Fighter III: Combat and character movement
- Super Mario World: Platforming and exploration
- The Last Night: Lighting and cinematic atmosphere

### Main Characters

- Ainan: Playable protagonist
- Jennifer: Heroine
- Maliha: Main antagonist
- Mini Maliha: Secondary enemies and mini-boss

### Environments

1. The Last Sunset
2. The Chase
3. Industrial Encounter
4. Final Showdown
5. Together Again

### Production Standards

- Consistent pixel density
- Consistent character proportions
- Transparent character sprites
- Frame-by-frame animations
- Consistent foot anchoring
- Multilayer parallax backgrounds
- Cinematic lighting
- Original character graphics
- Properly licensed resources
- Responsive desktop and mobile interface

### Restrictions

- No static character portraits used as fighters
- No mismatched art styles
- No stretched character sprites
- No generic emoji-based weapons
- No unnecessary interface clutter
- No proprietary game asset copying
